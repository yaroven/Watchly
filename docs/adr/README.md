# Architecture decision records

One file per decision, newest number last. Format: Context / Decision / Consequences.

These were reconstructed from the code, the `Makefile`, `schema.prisma` and
`pnpm-workspace.yaml` — several quote rationale that already existed as comments in
those files and was invisible to anyone not reading them.

Add a record when a decision would otherwise have to be rediscovered by reading
several files, or when you deliberately rejected an obvious alternative. Supersede
rather than edit: a record that was true once stays part of the history.
